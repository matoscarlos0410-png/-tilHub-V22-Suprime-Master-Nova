ÚTILHUB V22 — NOVA FLOW
========================

DESCRIPCIÓN
-----------
ÚtilHub V22 es una página web de herramientas útiles para el día a día.

Incluye:
- Calculadora
- Porcentajes
- Descuentos
- Regla de tres
- Conversiones
- Tiempo
- Cronómetro
- Temporizador
- Reloj
- Notas
- Tareas
- Lista de compras
- Herramientas de texto
- Diccionario
- Generador de contraseñas
- Generador aleatorio
- Código QR
- Y muchas herramientas más.

NOVA FLOW
---------
NOVA FLOW es el sistema de animación principal de ÚtilHub.

En V22 la animación está diseñada para funcionar en TODO el sitio web,
no solamente en la portada.

Características:
- Fondo animado global.
- Partículas y efectos dinámicos.
- Movimiento relacionado con el cursor.
- Efecto de desplazamiento.
- Diferentes modos visuales.
- Control de intensidad.
- Control de rendimiento.
- Compatibilidad con dispositivos móviles.
- Compatibilidad con reducción de movimiento.

ARCHIVOS
--------
ÚtilHub V22 utiliza estos archivos:

1. index.html
2. style.css
3. script.js
4. manifest.webmanifest
5. sw.js
6. README.txt

INSTALACIÓN EN GITHUB
---------------------
1. Crea un repositorio nuevo en GitHub.

2. Coloca todos los archivos en la carpeta principal
   del repositorio.

3. Asegúrate de que los nombres sean exactamente:

   index.html
   style.css
   script.js
   manifest.webmanifest
   sw.js
   README.txt

4. Guarda los cambios.

5. Entra en:

   Settings
   → Pages

6. En "Build and deployment" selecciona:

   Source: Deploy from a branch

7. Selecciona:

   Branch: main
   Folder: / (root)

8. Guarda la configuración.

9. Espera unos momentos.

10. GitHub mostrará la dirección de tu sitio web.

PWA
---
ÚtilHub V22 incluye configuración para funcionar como
una aplicación web instalable.

Para que el Service Worker funcione correctamente,
el sitio debe abrirse mediante HTTPS.

GitHub Pages proporciona HTTPS automáticamente.

SERVICE WORKER
--------------
El archivo:

sw.js

permite almacenar archivos de ÚtilHub en caché.

Esto ayuda a:
- Cargar más rápido.
- Mantener recursos disponibles sin conexión.
- Actualizar automáticamente la aplicación.
- Permitir características de aplicación web.

IMPORTANTE
----------
Si modificas archivos importantes y el navegador continúa
mostrando una versión anterior:

1. Actualiza la página.
2. Cierra y vuelve a abrir ÚtilHub.
3. Si es necesario, borra la caché del sitio.
4. Vuelve a cargar la página.

NOVA FLOW Y RENDIMIENTO
-----------------------
Si el dispositivo funciona lentamente:

- Reduce la intensidad de NOVA FLOW.
- Selecciona un modo de rendimiento más alto.
- Desactiva las animaciones si es necesario.

En dispositivos móviles se recomienda utilizar una
configuración de rendimiento equilibrada.

PRIVACIDAD
----------
Las herramientas locales de ÚtilHub almacenan sus datos
principalmente en el navegador mediante localStorage.

Esto permite conservar:
- Favoritos.
- Herramientas recientes.
- Notas.
- Tareas.
- Lista de compras.
- Configuraciones.

No se deben colocar contraseñas reales ni información
confidencial en herramientas de demostración.

COMPRAS Y COMIDA
----------------
Las herramientas de comida y compras sirven para facilitar
la búsqueda.

ÚtilHub NO realiza automáticamente las compras ni los pedidos.

El usuario debe revisar el sitio externo y realizar
personalmente cualquier compra o pedido.

SIN IA
------
ÚtilHub V22 no necesita inteligencia artificial para
funcionar.

Las herramientas principales funcionan directamente
en el navegador.

OBJETIVO
--------
Crear una plataforma sencilla, rápida y útil donde una
persona pueda encontrar diferentes herramientas en un
solo lugar.
